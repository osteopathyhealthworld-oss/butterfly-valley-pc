# Долина бабочек — игра для Windows

Приключение Паки с живым поселением, исследованием долины и общими стройками.
Текущая глава — «Свет над долиной». Godot 4.4.1, Windows x64.

## Скачать и запустить

Проверенные версии публикуются в **Releases** этого репозитория.
Скачайте `ButterflyValley-Windows.zip`, распакуйте архив целиком и запустите
`ButterflyValley.exe`. Файл `ButterflyValley.pck` должен лежать рядом.
Для проблемного драйвера Vulkan предусмотрен `Start-Compatible.bat`.
Интернет во время игры не требуется; устанавливать Godot игроку не нужно.

**Статус переноса:** проект и настройка сборки подготовлены. До первого успешного
задания Actions проверенного Windows-архива нет. Эти исходники не подтверждают
внешний вид, звук или частоту кадров на компьютере.

При подготовке переноса прошли компиляция 39 скриптов, проверки правил главы,
общих строек и восстановления сохранений в Godot 4.4.1 с Dummy renderer,
а также семь автономных проверок загрузчика ресурсов Python.
Полный импорт и экспорт Windows ещё должны пройти в Actions.

## Что можно делать

- Заказать каменную или ивовую переправу, ремонтировать крышу и строить мастерскую.
- Поручить жителям доставку, выбрать приоритет проекта и приостановить его.
- Принести материалы самому, помочь строительству или исследовать озёра.
- Позвать Бруно с собой; пока он сопровождает Паки, он не строит.
- Варить смолу и чай, собирать припасы, восстанавливать луг и готовиться к ливню.
- Зажечь маяк и помочь каравану найти путь в долину.

WASD — движение; Shift — бег; E — действие; J/M — журнал и карта;
ПКМ — поворот камеры; колесо — расстояние; F11 — полный экран.
Подробности: [инструкция игроку](game/PLAY-WINDOWS.md).

## Автоматическая сборка

Изменение основной ветки или ручной запуск **Actions → Build Windows → Run workflow**
запускает проверки, импорт ресурсов и экспорт Windows. Архив публикуется только
после успешных проверок. Он содержит игру, инструкции, авторов и контрольные суммы.

Код находится здесь. Модели, текстуры и звук сборка получает
из отдельного закрытого хранилища; права перечислены в CREDITS.md.
Четыре файла персонажей имеют отдельные исходные условия и не включаются
в публичный Git. Разовая настройка — [SETUP-ACTIONS.md](SETUP-ACTIONS.md).
Без этих файлов проверка запрещает выпуск с временными фигурами вместо персонажей.

Godot-проект расположен в `game/`.
Текущие механики описаны в [дизайне главы](game/LIVING-VALLEY-DESIGN.md),
дальнейшие этапы — в [плане развития](game/GAMEPLAY-RESEARCH-AND-ROADMAP.md).
Порталы, вариативные вылазки и активная оборона пока не реализованы.

Это отдельный ПК-проект. Здесь нет сайта, серверных настроек, выкладки на Timeweb
или сборки браузерной версии. Игра распространяется бесплатно.
Публичность исходников не меняет условия материалов: [LICENSE.md](LICENSE.md), [CREDITS.md](CREDITS.md).
