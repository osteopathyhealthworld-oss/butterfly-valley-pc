## Подготовленные файлы внутри этой ветки

В папку [`library/prepared/`](library/prepared/) добавлены **45 моделей** (28 самостоятельных GLB и 17 glTF с геометрией и текстурами) для ближайших опытов с хозяйством:
- 17 Kenney: брёвна, пень, грядка, кукуруза на грядке, ограды, костёр, дорожка, яблоко, морковь, лук, кукуруза, хлеб, помидор, стол, книги, шкаф;
- 11 Gobkit: две коровы, овца, свинья, ягнёнок, колибри, петух, долгопят, бабочка `Swallowtail`, муравей-листорез и бражник.
- 17 KayKit: десять ресурсов для крафта (брёвна, доски, каменные блоки, слитки, ящик, поддон) и семь инструментов (топор, молоток, кирка, лопата, пила, ведро и наковальня); все внешние `.bin` и общие PNG-текстуры добавлены рядом.

Модели Gobkit действительно содержат скелеты и встроенные анимации. У всех 11 добавленных животных и насекомых проверено наличие скелета и анимаций на уровне GLB; у `Swallowtail.glb` прочитано 23 именованных клипа. Машиночитаемый индекс [подготовленных моделей](library/prepared/catalog.json) перечисляет пути, необходимые файлы и предполагаемые взаимодействия (пока не реализованные). Их работоспособность **в Godot пока не испытана**.

Все файлы доступны в ветке непосредственно; никаких новых покупок для них не требуется. Их ещё не подключали к сценам, коллизиям и поведению персонажей.

## Как получить остальную библиотеку на Windows

1. Установить [Git for Windows](https://git-scm.com/download/win) (Godot и GitHub Actions для самой загрузки не нужны).
2. Скачать или открыть эту ветку репозитория.
3. Из корня репозитория запустить:

```powershell
powershell -ExecutionPolicy Bypass -File .\godot\butterfly-valley\prepare-world-library.ps1 -Profile Core
```

Для всех папок этих открытых репозиториев:

```powershell
powershell -ExecutionPolicy Bypass -File .\godot\butterfly-valley\prepare-world-library.ps1 -Profile Full
```

При повторном запуске скачанное не удаляется; Git-источники закреплены на известных коммитах, архивы Gobkit сверяются по размеру и SHA256. При расхождении скрипт останавливается. Кэш по умолчанию: `%LOCALAPPDATA%\ButterflyValley-AssetLibrary`. Можно передать `-CacheDirectory "D:\ButterflyAssets"`.

Скачивание большого профиля может занять время и потребовать **нескольких гигабайт диска**, включая исходные FBX, текстуры, Git-историю и временные файлы. Для проверки первого поселения достаточен `Core`.

## Художественные и технические ограничения

- Окружение: ориентир **Quaternius Medieval Village + Fantasy Props + Stylized Nature**.
- Kenney обладает очень простой геометрией и может потребовать масштабирования и коррекции материалов. Использовать выборочно; некоторые объекты лучше оставить для дальнего плана.
- Полигонаж главных героев существенно выше, поэтому новое население обязательно оценить в одной сцене вместе с Паки и Бруно.
- Готовая модель с анимациями не гарантирует, что анимации подойдут чужому скелету.
- Весь кэш оставлен **вне Godot-проекта**. Импортировать тысячи объектов в `res://` сразу нельзя: это замедлит подготовку проекта и увеличит размер браузерной сборки. Отбирать экземпляры по мере создания сцены.
- Совместимость с **Godot 4.4.1 Compatibility/Web** и работа на 8 ГБ ОЗУ остаются обязательными.
- Лицензии моделей Plumberry и платных вариантов проверяются отдельно; их в эту открытую библиотеку не включали.
- После загрузки файлов проект сам по себе не получает работающую экономику или строительство — взаимодействия, ИИ и сохранение изменений будут добавлены после проверки конкретных сцен.

## Границы этой работы

Изменения сделаны **только** в отдельной экспериментальной ветке. `production`, `main`, актуальную экспериментальную ветку игры и GitHub Actions мы не изменяли и не запускали. Дальнейшее соединение с NPC, над которыми сейчас работают в другой ветке, выполнять только после сверки их моделей и действующей игровой логики.
